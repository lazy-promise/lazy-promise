---
title: Installation
---

```bash
npm install @lazy-promise/core
```

LazyPromise supports all modern browsers, Node.js 20.16.0 and later in the 20.x series, and Node.js 22.3.0 and later.

To try it without installing anything, you can use the [Playground](https://stackblitz.com/edit/lazy-promise?devToolsHeight=1000&file=index.ts).
